# Suite integral (E2E con Playwright)

```bash
cd tests
npm install                      # playwright (no baja navegadores)
node server.js &                 # servidor estático en :8124 (sin dependencias)
node suite.js                    # necesita un Chromium: npx playwright install chromium
# o, con uno ya bajado:
PW_EXE=C:/Users/<vos>/AppData/Local/ms-playwright/chromium-1228/chrome-win64/chrome.exe node suite.js
# o el Chrome del sistema:
PW_CHANNEL=chrome node suite.js
```

- **T1** Herramienta personal: sumas exactas, chip 5%, ayuda invisible tras recarga, guardar/comparar mes.
- **T2** Trimestre completo de **3 meses** con dos equipos (TIBURONES y PULPOS, elegidos por sticker) y **scores exactos calculados a mano**: `A = 47.700`, `B = −20.075`. Cubre trampa, los tres eventos (incluida la tableta en cuotas), austeridad, fiado que viaja de mes en mes, retomar tras recarga, proyector tardío, guards, boletín, reveal, podio y análisis.
- **T3** Revancha limpia. **T4** Timeout real de 60s ("Juan decidió solo", sin puntos). **T5** Estáticos (IDs, sw, piel de 12 Meses embebida, 12 stickers). **T6** Reloj que cierra solo, teclado, billetes arrastrados, botón TODO. **T7** Control del facilitador y guard de reinicio. **T8** Mercado de a una (swipe). **T9** Subasta a ciegas. **T10** Tutorial.

⚠️ Los scores esperados dependen de TODAS las constantes de la economía (`MESES`, `ptsDest`, trampas −1500, eventos, bonus). Si tocás una, recalculá a mano antes de culpar al código: el camino de cada equipo, mes por mes, está en `TRASPASO.md`.
